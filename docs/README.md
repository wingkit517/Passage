## 这套文档怎么读

文档按**阅读场景**分层组织，每份文档头部都写明「职责 / 体积 / 什么时候读 / 不包含什么」：

| 层 | 文档 | 什么时候读 |
|---|---|---|
| **L0 地图** | [`Passage_0 文档地图.md`](./Passage_0%20文档地图.md) | **每次开工第一个读**，然后只读需要的 |
| **L1 必读** | [`AGENTS.md`](./AGENTS.md)（纪律红线）· [`Agent交办事项.md`](./Agent交办事项.md)（现状与下一步） | 每次开工必读 |
| **开工前置** | [`AGENTS_记录规范.md`](./AGENTS_记录规范.md) · [`AGENTS_平台规范.md`](./AGENTS_平台规范.md) | 写记录 / 跑服务之前 |
| **L2 按需** | [`Passage_1`](./Passage_1%20功能与逻辑.md)（业务）· [`Passage_2`](./Passage_2%20产品设计与信息架构.md)（产品）· [`Passage_2b`–`2g`](./Passage_0%20文档地图.md)（子主题）· [`Passage_2d`](./Passage_2d%20技术方案与质量门槛.md)（技术） | 做对应的事时 |
| **L2 状态** | [`Passage_3`](./Passage_3%20交付状态.md)（进度）· [`Passage_3b/3c/3e`](./Passage_0%20文档地图.md) | 查进度 / 验收 / 查地点 |
| **流水** | [`development-logs/`](./development-logs/README.md) | 找某次任务干了什么（**不要通读**） |
| **归档** | [`archive/`](./archive/README.md) | 非追溯不读 |

一句话：**90% 的任务按地图 §2 的阅读清单表走，落在 3–35 KB；全量通读只是兜底。**

## 三分钟上手（人类版）

1. **想看效果**：仓库根起 `python3 -m http.server 8777`，开 `http://127.0.0.1:8777/`（口径见 [`AGENTS_平台规范.md`](./AGENTS_平台规范.md) §1）。
2. **想看这次行程**：[`Passage_3e 交付明细与对照矩阵.md`](./Passage_3e%20交付明细与对照矩阵.md)——17 处地点（第 1 天中山 3 处 + 第 2 天澳门 14 处）的来源、坐标、营业时间、价位。
3. **想知道现在做到哪**：[`Passage_3 交付状态.md`](./Passage_3%20交付状态.md) + [`Agent交办事项.md`](./Agent交办事项.md)。
4. **想改代码**：先读 [`AGENTS.md`](./AGENTS.md)（§5 硬约束，尤其「渲染层零硬编码」）。
