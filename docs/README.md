## 一句话结论

**开源社区有可复用的「功能基座」（TREK，8/8 能力覆盖），但没有可复用的「产品形态」。**

所以要做的不是「换皮」，而是**拿 TREK 当后端，自建体验层**——因为小红书那篇的真正价值（原创城市插画、鸟瞰地图、电影式镜头推进）在开源社区没有对应物。

## 已经跑起来的原型

`app/` 里是一个**零构建的静态原型**，覆盖了 `02-产品设计方案.md` 里 Phase 1（MVP）与 Phase 2 的「路线自动排序」：

```bash
cd app && python3 -m http.server 8777 --bind 127.0.0.1
# 打开 http://127.0.0.1:8777/
```

两个视图：行程总览（规模统计 + 每天路线卡）、地图工作台（三栏联动）。

**当前数据：中国澳门 · 半岛与路环（13 个地点 / 2 天 / 20 张配图）**，来源是用户提供的 7 条小红书笔记链接。

原型截图见 [`assets/原型截图-澳门/`](./assets/原型截图-澳门/)（9 张，含配图、大图查看、关闭后空态、移动端浮层）。

**已经验证可用的核心能力**：

- 倾斜鸟瞰地图（pitch 50°）+ 真实 3D 建筑挤出
- 13 个地点的编号标记，按天着色（`1-1`…`1-5` / `2-1`…`2-8`），两位数编号自动收字号
- 每天一条彩色虚线路线 + 相位平移的「流动」动画
- 点击地点镜头飞近（zoom 16.2 / pitch 55°）+ 详情卡展开
- **路线自动排序**：最近邻 + 2-opt，带前后距离对比、一键撤销、起点锁定
  （实测：第 1 天 2.7 km，锁定起点 −0.9% / 放开 −9.2%；第 2 天 8.4 km，锁定 −4.4% / 放开 −6.2%）
- 地点详情含**地址 / 营业时间 / 电话 / 价位 / 怎么去 / 坐标精度**，逐条标注来源
- **每处地点带 1–2 张来自笔记的实拍配图**，图下带说明，点图可看大图
- **详情卡可关闭**：右上角 ×、Esc、点地图空白处；未选中时按钮自动隐藏
- 左侧列表带 42px 缩略图（专用 `thumb.jpg`，13 张共约 96 KB，不是直接塞原图）
- 移动端底部抽屉布局、减少动效开关
- **数据与渲染完全解耦**：`app.js` 里没有城市名 / 天数 / 地点数的硬编码

**还没做**：真实后端、攻略导入产品化、协作、预算、离线。这些需要接入后端（建议复用 TREK）。

> ⚠️ 必须走 http 服务打开，不能双击 `file://` —— 地图瓦片是跨域请求，`file://` 下会被浏览器拦截。

## 三分钟读完的要点

### 1. 开源调研结论（详见 01）

| 层面 | 结论 |
|---|---|
| 功能基座 | ✅ 存在。`liketrek/TREK`（AGPL-3.0，≈14.4k Star，2026-09-26 仍更新）对 8 项核心能力全覆盖，一条 `docker run` 起服务，自带简繁中文 |
| 产品形态 | ❌ 不存在。没有任何开源项目做「视觉叙事型个人旅行工作台」 |

**核心判断**：TREK 是**工具型**（把旅行管起来），小红书那篇是**叙事型**（把旅行记住并讲出来）。信息架构从根上不同，**换皮做不出来**。

### 2. 产品定位（详见 02）

**一个把散落各处的旅行攻略，收敛成一条走得通的路线的工作台。**

- 两条原则：**顺路优先于好看** · **一个主场，做透**
- 一个主场：地图工作台（加一个总览入口）。不做行后记录
- v1 明确不做：多人算账、实时比价、社交 feed、全球城市（只做澳门）

### 3. 技术路径（详见 03）

```
自建体验层（原型：原生 JS 静态页 / 目标：React 19 + MapLibre GL JS）   ← 主要工作量
      ↓
复用 TREK 能力层（行程/协作/预算/附件/导出/离线）
      ↓
自建内容层（攻略采集：笔记链接 → 结构化地点 + 资料来源管理）          ← 产品护城河
```

## 数据来源（澳门行程）

| 来源 | 用途 |
|---|---|
| 用户提供的 **7 条**小红书笔记链接 | 地点清单、正文、推荐菜、描述、**全部 20 张配图** |
| 笔记内的**门店照片与菜单照片** | 地址、营业时间、电话、价格、出炉时间 |
| `photon.komoot.io`（OSM 数据） | 坐标（按楼名 / 街道名检索，逐条标注精度） |
| `webmap.gis.gov.mo` 街道门牌查询系统 | 门牌号 → 楼宇名反查（如「看台街 198 号」→ 信託花園银成阁） |

**已知缺口**：好利是咖啡小食只有街道级坐标（±60m）；十月初五馬路是街道级（±80m）；伙牛的电话后 2 位未能从照片辨认；第 4 个地点链接失效；路環圖書館没有独立配图（笔记未单拍，用所在街区街景并在说明里写明）。

> ⚠️ **配图版权**：20 张配图均取自用户提供的小红书笔记原图，**仅限本次行程自用**，不得对外发布或作产品素材。

> ⚠️ **本机网络环境**：`nominatim.openstreetmap.org` / `www.openstreetmap.org` 被本地代理拦截（HTTP 000），
> `overpass-api.de` 一律返回 406，`overpass.osm.ch` 数据库为空。**可用的是 `photon.komoot.io`。**
> 换机器部署时这段结论需要重测。详见 `03-技术实现方案.md` §3.3。
