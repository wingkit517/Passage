| | 第 1 天 | 第 2 天 |
|---|---|---|
| **主题** | 澳门半岛 · 祐汉早餐 → 望德堂 → 大三巴 | 路环岛 · 市区老街 → 竹湾 → 黑沙 |
| **时间窗** | 07:30 – 14:00（上午到午后） | 12:00 – 17:40（下午到傍晚） |
| **地点数** | 5 | 8 |
| **建议停留** | 约 2.8 小时 | 约 3.8 小时 |
| **主要交通** | 步行（半岛内最远 1.5km） | 公交 + 步行（三段公交，约 1.5 小时） |
| **地理范围** | 北纬 22.197–22.213，东经 113.539–113.551 | 北纬 22.113–22.121，东经 113.550–113.571 |

**合计**：13 处地点 · 25 道推荐吃食 · 6.5 小时建议停留 · 20 张配图

### 为什么这样排

1. **第 1 天在半岛、第 2 天在路环，不混。** 两地直线相距约 10km，跨海通勤单程 45 分钟以上。混在一天里，路上时间比玩的时间长。
2. **路环排在下午。** 路环半日线含「市区 → 竹湾 → 黑沙」三段，公交段本身就占 1 小时以上。按笔记原表 12:00 出发、16:30 收尾，正好一个下午。
3. **顺序被营业时间卡死**（这是本次编排的核心约束）：

| 约束 | 后果 |
|---|---|
| 好利是 07:00 开门 | 只能它当第一站 |
| 薈真集 10:30 才开门 | 早餐后必须留出约 2 小时空档（可在祐汉街市 / 关闸一带走） |
| 伙牛 11:00 开门 | 午餐不能早于 11:00 |
| 鐵餅號 12:00 才开门、周一店休 | 下午茶不能早于 12:00；**避开周一** |
| Bamu 出炉 10:00 / 12:00 / 14:00 / 16:00 | 13:30 到，正好等 14:00 那炉 |
| 安德魯 07:00–21:00 | 路环第一站没有时间压力 |
| 海滩、街巷、码头 | 全天开放，只受光照与公交班次影响 |
| 糖朝盛世 15:00 才开门 | 只能做路环回来的收尾（17:00 到）或夜宵，不能排在白天 |

> ⚠️ **周一不要走第 1 天下午那一段**——鐵餅號周一店休。
