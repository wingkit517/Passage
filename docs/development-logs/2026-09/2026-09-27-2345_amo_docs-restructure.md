## 七、问题与踩坑

- 正则 `#{1,2}` 会把 `###` 吃成二级标题（前两个 # 被匹配）——加 `(?!#)` 修复。
- 代码块里的 `# 注释`（如 `# 打开 http://…`）会被当标题——必须跟踪 ``` 围栏状态。
- 已提炼进 `engineering/踩坑与原理.md` §4。
