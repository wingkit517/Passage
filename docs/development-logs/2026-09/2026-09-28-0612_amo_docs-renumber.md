## 七、问题与踩坑

- 级联替换风险：朴素顺序 sed（2f→2e 后再 2g→2f）会把刚改出的 2f 再改成 2e；用单遍正则 + 前瞻断言规避。
- 无 `Passage_` 前缀的编号写法（如维护约定 §3 的 `_2f/2g`、地图「3e 占大头」）批量替换覆盖不到，须单独 grep `_2f|_2g|_3e` 补漏。
