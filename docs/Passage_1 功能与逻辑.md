### P0 — v1 必须做（决定产品是否成立）

| 模块 | 功能 | 验收要点 |
|---|---|---|
| M1 地图工作台 | 鸟瞰地图 + 缩放拖拽 + 地点标记 | 倾斜视角下建筑有立体感；60fps 拖动 |
| M2 行程面板 | 多日 Tab + 当日路线 + 地点列表 | 切换天时地图与列表同步 |
| M3 地点详情卡 | 完整字段（时段/时长/吃/看/来源） | 字段齐全，来源可点开 |
| M4 路线串联 | 按天用彩色虚线串联，跟随地图 | 每天颜色不同，线随地图移动 |
| M5 镜头动效 | 点击地点，镜头平滑飞近 | 过渡自然，不晕（可关闭动效） |
| M6 行程总览页 | 规模统计 + 每日路线卡，点击进入地图 | 打开首页 5 秒内明白「这是几天、去哪、怎么走」 |
| M7 路线自动排序 | 最近邻 + 2-opt，支持锁定锚点 | 排序结果不出现明显折返；可一键回到手工顺序 |
| M8 移动端适配 | 768px 以下独立布局 | 手机上行程面板可收起/展开 |

## 二、核心交互流程

### 流程 A：从零到一份行程（行前）

```
打开首页（行程总览）
   ↓ 点「新建行程」
选城市（v1：澳门）+ 天数
   ↓
系统给出「推荐路线」候选（基于预置攻略库）
   ↓ 用户勾选想去的 / 划掉不想去的
   ↓
地图工作台生成：每天自动分组 + 按地理集中度排序
   ↓ 用户拖拽微调（地点可在天之间拖）
   ↓
点任意地点 → 详情卡展开 → 看吃什么、看什么、停留多久
   ↓
行程定稿 → 生成只读分享链接 / 导出
```

### 流程 B：旅行当天使用（行中）

```
打开首页 → 行程总览 → 点「第 2 天」卡片
   ↓
带着当天筛选状态进入地图工作台
   ↓
看到当天路线（彩色虚线 + 编号标记）
   ↓ 点「下一个地点」
   ↓
镜头飞近 + 详情卡展开（含导航跳转按钮）
   ↓
一键跳转外部地图导航
```

> **v1.1 移除**：原流程 C「回来后整理成纪念品」已删除。产品在 S2 结束后即完成交付，不承担行后环节。
