## §6 交接注意事项

1. **改数据必改文档**：`data/places.js` ↔ `Passage_3c 交付明细与对照矩阵.md` 同源。
2. **收尾三件事**：更新本文 → 写/更新开发记录 → 跑 `bash docs/tools/doc-size.sh`（EXIT=0）。
3. **推送**：用户要求每次修改完推送远端。若 `ssh.github.com` 报 banner exchange 超时，**先直连 `ssh -T git@ssh.github.com -p 443` 确认凭据，再重试 push**——那是沙箱 DNS 把域名指到 sinkhole（`198.18.13.96`），不是凭据问题。
4. **别信下标**：地点行序会随新增漂移，脚本一律按 `data-id` 定位。
5. **未核实就是未核实**：写进 `Passage_3b` §三，不要写进正文当既成事实。
